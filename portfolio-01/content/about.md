# 문제를 구조화하고, 필요한 기술을 연결해 안정적인 결과로 만드는 개발자입니다.

## 소개

백엔드 중심으로 서비스를 설계하고 구현하는 과정에서 요구사항을 명확한 흐름과 데이터 구조로 바꾸는 일을 좋아합니다.

새로운 기술을 단독으로 보는 것보다, 기존 문제와 어떻게 결합해 더 나은 결과를 만들 수 있는지 고민합니다.

## 핵심 가치관

### 창의성

이모티콘: 💡

정해진 방식만 반복하기보다 문제의 맥락을 다시 보고, 더 단순하거나 더 적합한 해결 방식을 찾으려 합니다.

### 결합성

이모티콘: 🔗

기술, 데이터, 사용자 흐름을 따로 보지 않고 서로 연결된 구조로 바라보며 구현합니다.
